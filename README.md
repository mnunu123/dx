# 할증레이더 (프로토타입)

선사 할증 공지를 읽어 표로 만들고, 내 화물에 붙는 할증을 계산하는 웹 프로토타입입니다.
2026 해운·항만·물류 AX 혁신 아이디어 공모전 출품작(E안).

- 화면: 개요, 공지함, 할증 타임라인(2026년 중동 사태 재현), 내 화물 계산기, 검증 리포트
- 정적 사이트입니다. 빌드 단계가 없고 로그인도 없습니다. 이 저장소를 Vercel에 Import하면 그대로 배포됩니다(Framework Preset: Other).
- 로컬에서 보기: `python3 -m http.server 8000` 후 http://localhost:8000

## 들어 있는 데이터

| 파일 | 내용 |
| --- | --- |
| `data/db.json` | 공지 80건의 제목·게시일·원문 링크, 할증 732개(근거 구절 발췌 포함). 45건은 사람이 원문과 대조한 정답, 35건은 AI 추출(사람 확인 전) |
| `data/scenario.json` | 부산→제벨알리 40' Dry 재현 시나리오 결과, KCCI 중동항로(KMEI) 주간 지수 |
| `data/report.json` | 추출 평가 결과, 틀린 사례, 처리 시간 측정값 |
| `assets/engine.js`, `assets/geo.js` | 할증 계산 엔진과 지역·항만 표(계산 테스트 16건 통과본) |

공지 원문 전체는 싣지 않습니다. 근거 구절(발췌)과 원문 링크만 둡니다. 데이터 생성 스크립트와 정답셋 작업 파일은 별도 작업 저장소에 있습니다.

## 출처

- 각 선사 홈페이지 공지(Maersk, MSC, CMA CGM, ONE, Evergreen, 장금상선, 흥아라인)
- KCCI 주간 지수: 한국해양진흥공사, 공공데이터포털

금액은 참고용입니다. 실제 청구는 선사 공지와 계약을 따릅니다.
